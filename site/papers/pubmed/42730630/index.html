dcHiChIP: A comprehensive Nextflow-based pipeline for multiscale analysis of chromatin architecture from HiChIP data.

Agarwal, Abhishek; Al Bkhetan, Ziad; Plewczynski, Dariusz
Bioinformatics (Oxford, England) · 2026-09-13 · 仅摘要 · 原文

该文介绍了一个用于HiChIP数据染色质架构分析的流程，与cpcdh基因家族无直接关联，但可能为相关研究提供技术参考。

摘要

MOTIVATION: Despite the growing use of HiChIP to investigate protein-directed chromatin architecture, a comprehensive and reproducible pipeline for analyzing these datasets-from raw reads to multiscale 3D genome features-remains lacking. Existing tools often focus on isolated components, such as loop calling or matrix generation, but fall short in integrating structural annotation, functional enrichment, and spatial modeling within a unified framework. To address this gap, we developed dcHiChIP, a modular, scalable Nextflow-based workflow that streamlines the analysis of HiChIP data, enabling both routine processing and in-depth exploration of chromatin organization and regulatory interactions. RESULTS: dcHiChIP enables robust and reproducible analysis of HiChIP datasets across multiple scales of chromatin architecture. It accepts raw sequencing data as input and generates high-quality loop calls, domain annotations, and 3D genome models. It also performs functional annotation and motif enrichment analyses. Applied to benchmark CTCF HiChIP datasets, dcHiChIP identifies major chromatin architectural features such as TADs/CCDs, A/B compartments, and chromatin stripes, and offers efficient, end-to-end execution with support for batch processing and workflow resumability. AVAILABILITY: dcHiChIP is publicly available on GitHub at https://github.com/SFGLab/dcHiChIP, with documentation at https://sfglab.github.io/dcHiChIP/. The software version used in this study is archived at Zenodo: https://doi.org/10.5281/zenodo.22030542. SUPPLEMENTARY INFORMATION: Supplementary data are available at Bioinformatics online.

摘要翻译

动机：尽管HiChIP在探究蛋白质导向的染色质结构中的应用日益增多，但目前仍缺乏一个全面且可重复的流程，用于分析这些数据集——从原始读段到多尺度3D基因组特征。现有工具通常聚焦于孤立组件，如环检测或矩阵生成，但未能将结构注释、功能富集和空间建模整合到一个统一框架中。为填补这一空白，我们开发了dcHiChIP，这是一个模块化、可扩展的基于Nextflow的工作流程，可简化HiChIP数据的分析，支持常规处理以及对染色质组织和调控相互作用的深入探索。结果：dcHiChIP能够在染色质架构的多尺度上对HiChIP数据集进行稳健且可重复的分析。它接受原始测序数据作为输入，并生成高质量的环检测、结构域注释和3D基因组模型。它还执行功能注释和基序富集分析。应用于基准CTCF HiChIP数据集时，dcHiChIP识别出主要的染色质结构特征，如TADs/CCDs、A/B compartments和染色质条纹，并提供高效、端到端的执行，支持批量处理和工作流可恢复性。可用性：dcHiChIP在GitHub上公开可用，网址为https://github.com/SFGLab/dcHiChIP，文档位于https://sfglab.github.io/dcHiChIP/。本研究中使用的软件版本已存档于Zenodo：https://doi.org/10.5281/zenodo.22030542。补充信息：补充数据可在Bioinformatics在线获取。
